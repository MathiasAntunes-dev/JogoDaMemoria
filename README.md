 Jogo da Memória: Letras e Mentes  

Um jogo educativo e divertido criado para celebrar o Dia Nacional do Livro (29 de outubro).  
A proposta é incentivar a leitura e o aprendizado por meio de uma atividade lúdica, inspirada em personagens, autores e elementos do universo literário.  

---

 Tecnologias utilizadas

-  HTML  
-  CSS  
-  JavaScript  
-  Inteligência Artificial (para geração de imagens)  

---

 Como jogar
